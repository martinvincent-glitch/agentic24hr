### 🚀 快速開始 (Quick Start)

- **直接運行網頁**：直接以瀏覽器開啟 [agentic_iot.html](file:///c:/pyt/agentic%20iot%20meeting/agentic_iot.html)（免安裝、零相依、支援純本機離線運行）。
- **3D 人偶動畫沙盤 (Humanoid Puppet Stage)**：真正具備「頭部、軀幹、雙臂雙腿肢體關節動畫」之 3D 人偶，代表使用者的角色人物（你｜AI 自主系統架構師）直接出現在畫面中！支援地面點擊目標光圈行走、WASD/方向鍵操控與快速導引按鈕。
- **雙主題擬真空間**：提供「🏠 智慧生活 (Smart Living)」與「🏭 智慧工程 (Smart Engineering)」即時切換，協同阿凱 (邊緣 SLM)、雅婷 (IoA 協商)、小芸 (動態檢索) 與陳課長 (反思驗證) 4 位多代理人人偶共演。
- **完整使用手冊**：詳細系統操作指南請參閱 [Agentic_IoT_User_Guide.md](file:///c:/pyt/agentic%20iot%20meeting/Agentic_IoT_User_Guide.md)。
